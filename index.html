ABOUT ROYAL CLUB

BUILT FOR THE EXPERIENCE.

A VIRTUAL GAME LIBRARY

Royal Club is a small games collection. The library is stored in JSON Server, so changes remain available after reloading the site.

Games can be created, read, edited, and deleted from the library view.

HOW TO USE IT

  1. Start JSON Server and the local web server using the project instructions.
  2. Open Game Library to browse or manage games.
  3. Choose Play on Blackjack to open the table.
BLACKJACK RULES AND VIRTUAL POINTS

Get closer to 21 than the dealer without going over. Number cards count as shown, face cards count as 10, and an ace counts as 1 or 11.

The dealer stands on 17. A natural Blackjack pays 3:2. Points are for play only and have no cash value.
